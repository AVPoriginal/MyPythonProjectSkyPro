## Домашнее задание к занятию 11.1
* написан модуль [generators.py](generators.py) с функциями:
- filter_by_currency(transactions) которая принимает список словарей с транзакциями и код заданной валюты,
    возвращает транзакции с заданным кодом валюты. Если требуемое значение ключа в словаре отсутствует, игнорирует транзакцию
- transaction_descriptions(transactions) которая принимает список словарей с транзакциями,
    возвращает строку описания транзакции из словаря. Если поле описания в словаре отсутствует, возвращает пустую строку
- card_number_generator(start, end) которая принимает десятичные целые начальное и конечное значение диапазона
    генерирует 16 значный номер карты, возвращает строку в формате представления номера карты - четыре октета через пробел
    при некорректном задании диапазона возвращает строку "Некорректное задание диапазона номеров"
* написаны тесты [tests/test_generators.py](../tests/test_generators.py) для всех функций модуля.
- набор тестовых данных расположен в виде фикстур в файле tests/test_generators.py

## Домашнее задание к занятию 12.1
* написан модуль [utils.py](utils.py) с функцией get_transactions(file_path)
которая принимает на вход путь до JSON-файла и возвращает список словарей с данными о финансовых транзакциях. Если файл пустой, содержит не список или не найден, функция возвращает пустой список. 
* написан модуль [external_api.py](external_api.py) с функцией get_amount_in_rub(transaction)
которая принимает на вход транзакцию и возвращает сумму транзакции (amount) в рублях, тип данных —float . Если транзакция была в USD или EUR , происходит обращение к внешнему API для получения текущего курса валют и конвертации суммы операции в рубли.
- Для конвертации валюты используется Exchange Rates Data API: https://apilayer.com/
- Для сокрытия чувствительных данных (токенов доступа для API) использованы переменные окружения из файла .env
- Создан шаблон файла .env
* написаны тесты для новых функций
- [tests/test_utils.py](../tests/test_utils.py) 
- [tests/test_external_api.py](../tests/test_external_api.py) 
- тестовые данные и функции определены в теле функций тестов
- для имитации подключений к API в тестах использованы Mock и patch.
* обновлен список зависимостей окружения в связи с установкой дополнительных пакетов
* редактирован файл readme.md
