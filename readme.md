## Домашнее задание к занятию 11.1
* написан модуль [generators.py](generators.py) с функциями:
- filter_by_currency(transactions) которая принимает список словарей с транзакциями и код заданной валюты,
    возвращает транзакции с заданным кодом валюты. Если требуемое значение ключа в словаре отсутствует, игнорирует транзакцию
- transaction_descriptions(transactions) которая принимает список словарей с транзакциями,
    возвращает строку описания транзакции из словаря. Если поле описания в словаре отсутствует, возвращает пустую строку
- card_number_generator(start, end) которая принимает десятичные целые начальное и конечное значение диапазона
    генерирует 16 значный номер карты, возвращает строку в формате представления номера карты - четыре октета через пробел
    при некорректном задании диапазона возвращает строку "Некорректное задание диапазона номеров"
* написаны тесты [tests/test_generators.py](../tests/test_generators.py) для всех функций модуля.
- набор тестовых данных расположен в виде фикстур в файле tests/test_generators.py
- положение декоратора тестовых данных для теста функции card_number_generator относительно других функций менять в тексте нежелательно, тк обнаружена ошибка в pytest  
* редактирован файл readme.md

## Домашнее задание к занятию 11.2
* написан модуль [decorarators.py](decorators.py) с функцией декоратора log
Декоратор log выводит в файл или на консоль следующие данные
- Имя функции
- время выполнения
- результат
- наличие и тип ошибки при выполнении
- входные параметры при ошибке выполнения
- время до сбоя при ошибке выполнения
* написаны тесты [tests/test_decorators.py](../tests/test_decorators.py) для вариантов верного и с ошибкой выполнения декорированных функций, и вариантов записи лога в файл или вывода на консоль
- тестовые функции определены в теле функций тестов 
* редактирован файл readme.md
