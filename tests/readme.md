## Тестирование

Тесты написаны с использованием библиотеки "Pytest"
на данный момент написаны тесты для тестирования
функций модулей masks.py , widget.py , processing.py
в модулях tests\test_masks.py , tests\test_widget.py
используются тестовые данные и фикстуры из файла 
tests\conftest.py и параметризация в тестах.
Тестовые данные для тестирования модуля processing.py
находятся непосредственно в модуле теста tests\test_processing.py

### Запуск тестов осуществляется командой 
 pytest --cov=src --cov-report=html

### Отчеты по тестированию можно найти в папке htmlcov после выполнения тестов
